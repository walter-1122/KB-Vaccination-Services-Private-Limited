# KB Vaccination Services (Private) Limited

Professional poultry vaccination and spray application website.

## Files
- index.html — complete website
- assets/style.css — responsive visual design
- assets/script.js — mobile menu, scroll reveals and demo contact form

## Important
The contact details in the website are placeholders and should be replaced with the company's real phone, email and service-area details before publishing.

The wording intentionally describes spray/vaccination services in a professional but non-medical-claiming way. Product-specific instructions, dosages and disease claims should only be added from the company's approved technical information.
